**🍲 Food List App**

A simple, clean React app for adding and managing a list of food items, built as a hands-on way to practice core React fundamentals like state, props, and component composition.

Built with: React 19 · Vite · Bootstrap · ESLint

**📖 About**

This isn't a complex app, and that's kind of the point. It was built to actually understand React fundamentals rather than just read about them: state management, controlled inputs, event handling, and breaking a UI into small, reusable pieces.

**🚀 Live Demo**


**✨ Features**

➕ Add food items instantly via keyboard (press Enter)
⚡ Real-time list updates using useState
🗂️ Graceful empty-state handling
🧩 Modular, component-based architecture
🎨 Styled with Bootstrap

**🚀 Getting Started**

**Prerequisites**
Node.js (v18 or higher recommended)
npm

**Installation**
bash

# clone the repo
git clone <your-repo-url>
cd FoodReactProject_1

# install dependencies
npm install

# start the dev server
```npm run dev

Then open http://localhost:5173 in your browser.

Other commands
bash
npm run build      # production build
npm run preview    # preview the production build
npm run lint       # run ESLint
```
